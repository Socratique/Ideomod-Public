# Reference Repositories for Ideomod (Forge 1.20.1)
# Use these as guides for implementing features

================================================================================
MECHANICAL / AUTOMATION
================================================================================
Create - https://github.com/Creators-of-Create/Create
  Branch: mc1.20.1/dev | License: MIT
  Use for: Mechanical blocks, kinetics, block entities, multiblocks, contraptions

MOBS & ENTITIES
================================================================================
Alex's Mobs - https://github.com/AlexModGuy/AlexsMobs

  Use for: Custom mob AI, GeckoLib animations, spawning, taming systems

FOOD & FARMING
================================================================================
Farmer's Delight - https://github.com/vectorwing/FarmersDelight
  License: MIT
  Use for: Custom crops, cooking systems, food items, wild crop generation

Tetra - https://github.com/mickelus/tetra
