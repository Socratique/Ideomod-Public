# Ideomod Changelog

## [2026-02-11] Machine Block
- Added MachineBlock - a mechanical building block with two features
  - Selective Stickiness: acts like a slime block, but only toward itself
    - isStickyBlock() returns true, canStickTo() only accepts other Machine Blocks
    - Exclusive with slime and honey (same pattern as vanilla honey vs slime)
    - Piston pushes Machine Block groups together; ignores all other blocks
  - Redstone Conduction: solid-state redstone dust
    - Stores power level 0-15 as blockstate property (same as dust)
    - Signal decays by 1 per Machine Block (lever 15 → 14 → 13 → ... → 0)
    - Powers adjacent non-Machine blocks (lamps, pistons, etc. activate)
    - Receives signal only from whitelisted redstone components
      (levers, buttons, repeaters, comparators, dust, observers, etc.)
      to prevent feedback loops with powered solid blocks
    - isRedstoneConductor = false to prevent vanilla propagation
  - Visual: color tint gradient from dark steel grey (0) to bright red (15)
    - Uses block/item color handlers (MachineBlockColor.java)
    - Grayscale texture tinted at runtime (same system as biome grass color)
- New file: MachineBlock.java (com.ideomancer.ideomod.block)
- New file: MachineBlockColor.java (com.ideomancer.ideomod.client)
- Updated: ModBlocks, ModItems, ModCreativeTabs registries
- Assets: blockstate (16 power variants → 1 model), block/item models with
  tintindex, placeholder grayscale texture, loot table, recipe
  (4 iron + 4 redstone + 1 slime = 1 machine block), pickaxe tag, lang
- Status: Working

### Implementation fixes during development:
- Power feedback loop: Machine Block originally accepted redstone signal
  from ALL neighbors, causing loops where it powered a lamp, the lamp's
  block became "weakly powered," and the Machine Block read that power
  back as input. Fixed with whitelist approach - only accepts signal from
  actual redstone components (levers, buttons, repeaters, etc.).
- Asymmetric stickiness: originally wanted slime to grab Machine Block
  but not vice versa. Forge's canStickTo is inherently symmetric (both
  blocks must agree). Attempted PistonEvent-based workarounds but they
  caused jank. Settled on clean mutual exclusion (Machine Block and slime
  don't interact at all), same pattern as honey vs slime in vanilla.

### Known issues / future work:
- True asymmetric stickiness (slime grabs Machine, Machine doesn't grab
  slime) would require mixins to modify PistonStructureResolver. Mixin
  infrastructure planned for future features.
- Texture is placeholder grayscale. Needs proper pixel art with circuit/
  mechanical pattern.
- Recipe is placeholder.
- Could add particle effects when powered (redstone sparkles).

## [2026-02-11] Oddstone Block
- Added OddstoneBlock - a strange stone with three unique properties
  - Mob Avoidance: all mobs refuse to pathfind over it
    - JSON config (config/ideomod/oddstone.json) lists affected mobs
    - Auto-generated on first launch with all vanilla 1.20.1 land mobs
    - Remove mobs from list to create exceptions
  - Redstone Insulation: does not conduct redstone signal
    - Behaves like glass for redstone purposes
    - Achieved via .isRedstoneConductor(false) in block properties
  - Sympathetic Movement: wireless slime block behavior
    - Each face searches outward (configurable radius, default 5) for nearest Oddstone
    - Max 6 connections per block (one per face), searches through solid blocks
    - Connected Oddstones form a group that moves together when pushed by piston
    - Sympathetic Oddstones push non-Oddstone blocks ahead of them
    - All pushed blocks count toward the 12-block piston limit
    - Exceeding 12 blocks cancels the piston push entirely
    - Obstructed sympathetic blocks (immovable block ahead) stay put
    - Chains through connected Oddstones (A grabs B, B grabs C, etc.)
- New package: com.ideomancer.ideomod.config (OddstoneConfig.java)
- New file: OddstoneMovementHandler.java (piston event listener)
- Assets: blockstate, block/item models, placeholder texture (purple-grey stone)
- Data: loot table, placeholder recipe (4 stone + 1 redstone = 4 oddstone), pickaxe tag
- Status: Working

### Implementation fixes during development:
- Mob pathfinding: Forge's getBlockPathType hook alone was not blocking mobs.
  Fixed by adding vanilla isPathfindable() override returning false (same
  approach as fences/walls). Also changed DANGER_OTHER to DAMAGE_OTHER in
  Forge hooks for stronger avoidance penalty.
- Sympathetic obstruction: initially the whole piston push would fail if ANY
  sympathetic oddstone was blocked. Changed so obstructed oddstones simply
  stay put, and only the 12-block limit causes a full piston failure.
- Sympathetic push chains: initially sympathetic oddstones could only move
  into empty spaces. Fixed so they push blocks ahead of them (like any
  piston-pushed block would), with those pushed blocks counting toward
  the 12-block limit.

### Known issues / future work:
- Sympathetic oddstone push chains don't trigger slime block stickiness.
  If a sympathetically moved oddstone pushes a slime block, blocks attached
  to that slime block don't come along. Works correctly for catalyst
  oddstones (directly pushed by piston). Fixing this requires deeper
  integration with PistonStructureResolver.
- Future feature: Oddstone should stick to slime blocks when the ODDSTONE
  moves (treated as sticky like slime), but slime blocks moving should NOT
  stick to Oddstone (one-way stickiness). This is the isStickyBlock/canStickTo
  pattern from Forge's IForgeBlock.
- Face search is axis-aligned only (directly in line with each face). Could
  be expanded to a half-sphere/cone search per face in the future.
- Texture is placeholder. Needs proper pixel art.
- Recipe is placeholder.

## [2026-02-04] Mining Drill Block
- Added DrillBlock
  - Directional placement like pistons (faces where player looks)
  - Redstone-activated: pulse to mine a 3x3 grid in front
  - Movable by pistons
  - Two visual states: off and on (glowing front when powered)
  - Skips indestructible blocks (bedrock, etc.)
  - Drops mined items near the drill position
- New package: com.ideomancer.ideomod.block
- Assets: blockstate (12 variants), 2 models, 5 textures
- Data: shaped recipe (iron + piston + redstone), loot table, pickaxe tag
- Status: Working
