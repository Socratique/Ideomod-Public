# Working notes

These are the project's own development documents, kept as they were written. They are detailed and useful, but they are working notes: some parts describe plans that changed, and some are behind the code. The [top-level README](../../README.md) was checked against the code and is the better guide to what the mod does today.

## Where the notes disagree with the code

Found while writing the top-level README (October 2026). The code is right in each case.

- **Portal activation.** The notes say a portal lights when every frame Oddstone is redstone-powered. The code lights it with a thrown ender pearl and never checks power.
- **Furnace Array size.** One passage gives a maximum of 3 wide by 2 tall. The code uses the config values, 5 by 5 by default.
- **Drill.** Marked "on hold" in the notes. In the code it works, has a recipe and is in the creative tab.
- **Machine Pulser.** Has no section in the technical reference, and is missing from its creative-tab list.
- **Specialisation table.** The reference lists three item-to-block mappings. There are seventeen.
- **Sympathetic scan.** Described as "at distance 1". The code scans the full radius along each axis line.
- **Redstone Rod recipe.** Described as diagonal. The recipe file is a vertical column.
- **Hollowstone.** "Any block item" can fill it: the code refuses blocks with block entities. "The inner block is never lost": only true for a player break without Silk Touch.
- **Config class.** One list still names `OddstoneConfig.java`. The class is `IdeomodConfig.java`.
- **Commands.** `/ideomod reload` exists alongside `/judgement`.
- **Machine GUI.** Height is 187 px and the menu carries 10 data values, not 151 px and 6. The second slot is also the Engine's fuel slot, not only the Pipe's transit slot.
- **Transmitter channel example.** Written as `minecraft:oddstone`; it is `ideomod:oddstone`.
- **Frameable blocks.** The tag has 341 entries, four of them Ideomod blocks.
